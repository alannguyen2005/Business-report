# SWD Chart Principles for PPTX

## 6 Principles Applied to Slides

| # | Principle | Slide Application |
|---|-----------|------------------|
| 1 | Understand context | Chart matches finding's intent |
| 2 | Choose appropriate display | Correct chart type for data relationship |
| 3 | Eliminate clutter | No gridlines, no top/right spines |
| 4 | Focus attention | ONE highlight + gray context |
| 5 | Think like a designer | Consistent margins, alignment |
| 6 | Tell a story | Chart title = insight, annotations = meaning |

## Chart Rules in Slides

| Rule | Requirement |
|------|------------|
| Background | `#F7F6F2` |
| Figure size | `(8, 4)` inches |
| DPI | 150 |
| Spines | Bottom + left only, `#E2E8F0` |
| Gridlines | None |
| Highlight | Max 1 color (#2554E7), rest gray |
| Labels | Direct on data — no legend box |
| Annotations | Max 3, AV-1 to AV-4 |

## Chart Title vs Slide Headline
- **Slide headline** = narrative frame: "The root cause is concentrated in one segment"
- **Chart title** = data claim: "Mid-Market accounts for 89% of revenue decline"
- These are DIFFERENT — never duplicate

## "So What:" Callout
- Mandatory on every chart slide
- Starts with "So what:" — contains ≥1 number — ≤20 words
- Rendered in dashed-border callout box below chart
